# Day 06 — Collections, Generics & LINQ

## Overview

Day 06 focuses on understanding C# Collections, Generics, and LINQ (Language Integrated Query).

The goal is to learn how to store, manage, search, filter, sort, and group data efficiently using C#.

## Topics Covered

### 01. Array
- Array declaration and initialization
- Accessing array elements
- `for` and `foreach` loops
- `Array.Sort()`
- `Array.IndexOf()`
- `Array.Exists()`

### 02. List
- Creating and initializing Lists
- Adding and accessing elements
- Working with custom classes
- `Add()`, `Remove()`, `Count`

### 03. Dictionary
- Key-value pair storage
- Adding and retrieving values
- `ContainsKey()`
- Updating dictionary values
- Iterating through Dictionary

### 04. HashSet
- Storing unique elements
- Preventing duplicate values
- `Add()`, `Remove()`, `Contains()`
- `Count`

### 05. Queue
- Understanding FIFO (First In, First Out)
- `Enqueue()`
- `Dequeue()`
- `Peek()`
- `Count`

### 06. Stack
- Understanding LIFO (Last In, First Out)
- `Push()`
- `Pop()`
- `Peek()`
- `Count`
- Browser history implementation

### 07. Generics
- Generic methods
- Multiple generic type parameters
- Generic classes
- `Box<T>`
- `Repository<T>`
- `Storage<T>`

### 08. LINQ (Language Integrated Query)

**Where()**
- Filtering elements based on conditions.

**Select()**
- Transforming and projecting collection elements.

**First()**
- Retrieving the first matching element.

**FirstOrDefault()**
- Retrieving the first matching element or the default value.

**Any()**
- Checking whether any element satisfies a condition.

**OrderBy()**
- Sorting elements in ascending order.

**OrderByDescending()**
- Sorting elements in descending order.

**GroupBy()**
- Grouping elements based on a property.
- Counting elements inside each group using `Count()`.

## Technologies Used

- C#
- .NET 10
- Visual Studio Code
- Git & GitHub

## Learning Outcomes

After completing Day 06, I can:

- Work with different C# collection types.
- Understand the differences between Array, List, Dictionary, HashSet, Queue, and Stack.
- Implement reusable code using Generics.
- Filter and transform data using LINQ.
- Search for elements using LINQ methods.
- Sort and group collection data.
- Work with custom classes and collections together.
